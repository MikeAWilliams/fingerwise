# Modules

One doc per module, named after its `src/` folder (for example `pitch.md`, `instrument.md`, `drill.md`). Each states the module's purpose, public interface, dependencies (what it may import), and tests.

Modules documented so far: [pitch](pitch.md), [instrument](instrument.md), [drill](drill.md), [judge](judge.md), [song](song.md), [abc](abc.md), [settings](settings.md), [staff](staff.md), [tab](tab.md), [graph](graph.md), [audio](audio.md), [app](app.md).

A module doc is written when the module is built. Until then, its intended shape is in the design of the feature that builds it, under [`../../features/`](../../features/).
