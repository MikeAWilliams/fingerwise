# Modules

One doc per module, named after its `src/` folder (for example `pitch.md`, `clef.md`, `instrument.md`, `drill.md`). Each states the module's purpose, public interface, dependencies (what it may import), and tests.

Modules documented so far: [pitch](pitch.md), [instrument](instrument.md), [drill](drill.md), [settings](settings.md), [staff](staff.md), [tab](tab.md), [app](app.md).

A module doc is written when the module is built. Until then, its intended shape is in `../../vision/vision.md#required-abstractions`.
