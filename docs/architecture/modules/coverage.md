# coverage

`src/core/coverage/index.ts`

## Purpose

Scores a timed song by coverage: how much of each note was played on the right note, in tune and on time, and how well the notes were separated. It takes detector readings and level blocks placed on the song's timeline in ms, classifies each reading against the note or rest due, and keeps segments, timing faults and separation as the run goes, so a display can draw them live. Pure: time comes only from the readings and the timeline, never from a clock or timer. It knows pitch, frequency and the song; it knows nothing of staff, audio or UI. Rules from [ADR 0009](../decisions/0009-timed-songs-scored-by-coverage.md) and the [F09 design](../../features/09-timed-scoring/design.md#scoring-model); built in [F09-S02](../../features/09-timed-scoring/stories/F09-S02-coverage-core.md).

## Public interface

Constants (the starting values from the design, in one block to tune in the live check): `EDGE_GRACE_MS = 40` (defined in [song](song.md) beside the release constants `RELEASE_SHARE` and `RELEASE_CAP_QUARTERS`, and re-exported here, so existing imports are unchanged), `WRONG_RUN = 3`, `TIMING_TOLERANCE_MS = 60`, `GAP_DIP_DB = 10`, `GAP_MEDIAN_WINDOW_MS = 100`, `MIN_SCORED_SPAN_MS = 50`, `RIGHT_NOTE_BAND_CENTS = 50`, `TRACE_SPAN_CENTS = 150`, and `MIN_GRADED_MS = 2 * EDGE_GRACE_MS + MIN_SCORED_SPAN_MS` (130).

Types:

- `CoverageReading`: the judge's `Reading` (`time`, `frequency`, `clarity`, `level`), with `time` in ms of song time: 0 is the first note's start, and the count-in has negative times.
- `EnvelopeBlock { time, level }`: the RMS level in dBFS of a short block, `time` its end in song time.
- `CoverageOptions { toleranceCents, checks: StabilityOptions, sounding(written): Pitch }`: the instrument's transposition is a parameter, so the core compares in sounding pitch and keeps written pitch for the tuning list.
- `Timeline { notes, rests, joins }` from `buildTimeline(song, tempo)`: each note `{ index, written, startMs, endMs, releaseMs, graded }` over its written length (not its slot), with `releaseMs` from song's `noteReleasesMs(song, tempo)` (0 for a note slurred into the next); each rest `{ startMs, endMs, graded }` between one note's end and the next note's start (more than 0.001 beat, as `songBars` finds them); each join `{ before, after, atMs, kind: "plain" | "slurred" }` between neighbours with no rest, from the earlier note's `slurred`. `graded` is a length of at least `MIN_GRADED_MS`.
- `scoredSpan(note, slurredStart): { startMs, endMs, releaseEndMs }` (F15-S01): the one span rule for a graded note. `startMs` is the note's start plus `EDGE_GRACE_MS` (none at a slurred start); `endMs` is where the release starts (`note.endMs - releaseMs`, the written end at a slurred end); the release zone runs from `endMs` to `releaseEndMs`, `EDGE_GRACE_MS` before the written end, and is empty when the release is the floor or the end is slurred. The [analysis](analysis.md) uses it too.
- `classify(reading, expected | null, options): Classified`: `{ kind: "right", inTune, cents }` when the reading passes the judge's [`passesChecks`](judge.md) and is within `RIGHT_NOTE_BAND_CENTS` of the expected pitch (in tune within the tolerance), `{ kind: "pending", nearest, cents }` when it passes but is another note (or any sound on a rest, where `expected` is null), and `{ kind: "silent" }` otherwise.
- `createCoverageRun(timeline, options): CoverageRun` with:
  - `pushReading(reading)`: readings in time order. The newest `WRONG_RUN - 1` readings can still change on a later push; everything before is settled.
  - `pushEnvelope(blocks)`: level blocks in time order.
  - `progress(): Progress`: `segments` (those of finished notes and rests, the same array growing, nothing in it changing), `open` (the segments of the notes and rests still open, recomputed each call), `timingFaults` and `notSeparated` (each found as its note finishes; the same arrays growing).
  - `finish(): CoverageResult`: settles every reading, finishes what is left and returns the result. Later pushes are ignored.
- `Segment { startMs, endMs, kind: "right-in-tune" | "right-out" | "wrong" | "silent", on: "note" | "rest", graded, points: { timeMs, cents }[] }`: a run of readings of one class inside one note or rest; `graded` is false in a note or rest too short to grade, which the lane never fills. A point is a sounding reading (right or confirmed wrong) with its offset in cents from the expected pitch (from the nearest note on a rest).
- `TimingFault { index, edge: "start" | "end", kind: "late" | "early" }` and `JoinFault { before, after, atMs }`.
- `CoverageResult`: `coverage` (0 to 1, null when nothing was graded), `inTune` (null with no right-note time), `graded`, `tooShort` (ungraded notes) and `tooShortRests`, `timing` (`startedLate`, `startedEarly`, `endedEarly`, `endedLate`, each `{ faults, withEdge }`), `separation { notSeparated, plainJoins }`, `tuning` (up to three `{ pitch, cents }`, written pitch), and `items`, the per-note and per-rest `ItemScore`s (`coverage`, `inTune`, `startEdge`, `endEdge`, `soundStartMs`, `soundedMs`), with the fault lists.
- `ItemScore.soundStartMs` (added in [F11-S01](../../features/11-score-analysis/stories/F11-S01-breakdown-and-habits.md)): on a graded note with a right reading, the start of the unbroken run of the expected pitch into its first right reading (the same walk back as the early-start check, so it can be before `startMs`, and it stops at a same-pitch neighbour's own readings). Set whether or not the start edge is blind; null with no right reading and on rests. `ItemScore.soundedMs`: on a graded rest, the time in its graced span covered by readings that pass the checks (pending or wrong); null on notes and ungraded rests. Both are additive: no figure changes.

## Rules

- **Classifying.** Each reading is classified against the note or rest due at its `time`. A passing reading that is not the expected note is pending; the same other nearest note for `WRONG_RUN` readings in a row confirms the run, and the whole run counts as wrong from its first reading. Until then, pending readings count as silent. A right, silent or different pending reading restarts the run. A reading before the first note or after the last note is kept for the edge checks but is in no segment. Each reading covers the time until the next one; the newest reading covers none until another comes (and at `finish`, as long as the interval before it). Readings are not capped, so a long hole in the readings keeps the last class.
- **Note coverage.** The share of the scored span (`scoredSpan`: from the start plus the grace to the release start) filled by right readings (in tune or not). In the release zone ([ADR 0011](../decisions/0011-release-allowance.md)) right sound counts as covered and adds to the note's scored time; a confirmed wrong run adds to the scored time only; silence and pending readings add nothing, so `coverage = min(1, covered / (span + zone time that counted))`. A note held for its full length scores as before, and a stop for tongue or breath costs nothing. The in-tune share counts right sound in the release too. At a slurred join the grace on that side is not cut: it is counted, and readings of the neighbour's pitch there fill it, but silence and any other pitch do not. A rest's coverage is its graced span's share filled by silent readings (pending ones included). Not-graded notes and rests have no coverage.
- **Song figures.** Coverage is the unweighted mean over graded notes and rests. A note's in-tune share is its in-tune right-note time over its right-note time; the song figure is the mean over graded notes with any right-note time. Timing figures count graded notes only.
- **Timing.** A note's start edge is its first right reading and its end edge the end of its last, even with silence between. Late: more than `TIMING_TOLERANCE_MS` after the start, or before the *release start* for an early end (`endMs - releaseMs`; the written end at a slurred end). Late end is judged from the written end. Early start or late end: the expected pitch's readings (passing, within the band) run unbroken from more than the tolerance before the start, or to more than the tolerance past the end, counting readings classified against the neighbours. A note with no right-note time has no edges. A same-pitch join where nothing shows the change gives no edge on either side: a plain join with no gap detected, and (an extension of the design) any slurred join. At a same-pitch join with a gap, the unbroken run stops at the note's own readings.
- **Separation.** For each plain join, from the earlier note's release start less `TIMING_TOLERANCE_MS` to `TIMING_TOLERANCE_MS` after the join: a reading that fails the checks, or a level block at least `GAP_DIP_DB` below the median of the blocks within `GAP_MEDIAN_WINDOW_MS / 2` either side, followed by a block back above that line within the same half-span. A join is looked at when its first note finishes. Slurred joins are skipped.
- **Finishing.** A note or rest is finished when the settled readings pass its end by `TIMING_TOLERANCE_MS + GAP_MEDIAN_WINDOW_MS`, so the late edge and the level check have what they need. Progress therefore reports faults and finished segments about 160 ms after a note ends; `open` shows the rest.
- **Tuning list.** For each written pitch, the mean offset in cents of every passing reading within `TRACE_SPAN_CENTS` of the expected pitch while a note of that pitch is due (graces included, ungraded notes included). Pitches whose mean is beyond the tolerance, worst first, three at most.

## Dependencies

`src/core/judge`, `src/core/pitch` and `src/core/song` only. No clock, timer or browser API.
