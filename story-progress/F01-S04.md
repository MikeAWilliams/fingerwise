- [x] Create `src/core/drill/index.ts`, importing only `../pitch` and `../instrument`:
  - `export type RandomSource = () => number` (returns a value in `[0, 1)`, like `Math.random`).
  - `export class DrillError extends Error` (name `"DrillError"`).
  - `export interface PoolOptions { lowest: Pitch; highest: Pitch; includeSharps: boolean }`.
  - `buildPool(instrument: Instrument, options: PoolOptions): Pitch[]`: `pitchesInRange(lowest, highest)`, filtered by `isNatural` when `includeSharps` is false, ascending.   - `drawPitch(pool: readonly Pitch[], previous: Pitch | null, random: RandomSource): Pitch`: throws `DrillError` on an empty pool; with one pitch returns it (AC4); otherwise picks uniformly from `pool` minus `previous` with `Math.floor(random() * candidates.length)` (AC2, AC3). `random` is a required parameter; the module never calls `Math.random` (AC10).

  - AC2: with a stepping fake random (`i / n` for `i` in `0..n-1`) every candidate is returned exactly once for a pool, with and without a previous pitch; a fake returning `0.999…` stays in bounds.
  - AC3: for every previous in the pool and many fake values, the result is never `previous`.
  - AC4: pool of one, with that pitch as previous and with `null`, returns it.
  - AC10: read `src/core/drill/index.ts` with `?raw` (as `core-imports.test.ts` does) and assert its imports are exactly `../pitch` / `../instrument` and it contains no `Math.random`.

## Sub-task 2: Card flow controller

Covers: AC6, AC7, AC8
- [x] Create `src/app/card-flow.ts` (plain TypeScript, no Preact) exporting `createCardFlow({ pool, random, delayMs, onChange })`:
  - State `{ pitch: Pitch; revealed: boolean }`. `start()` draws the first pitch with `previous = null`, starts `startRevealTimer(delayMs, reveal)` and calls `onChange`.
  - `step()`: if unrevealed, reveal now and cancel the timer (AC6); if revealed, draw the next pitch with the current one as previous, set unrevealed and start a new timer from zero (AC7). Exactly one of the two per call (AC8).
  - Timer expiry reveals (no-op if already revealed). `stop()` cancels any timer (used on unmount; S06 will use it for settings).
  - Uses `drawPitch` from `src/core/drill` and `startRevealTimer` from `./reveal`.
- [x] `tests/app/card-flow.test.ts` with `vi.useFakeTimers()` and a fake random:

  - AC7: `step()` when revealed shows a different pitch, unrevealed; it auto-reveals only after a full `delayMs` from that step (not from the original start).
  - AC8: a single `step()` from unrevealed leaves the same pitch revealed; a single `step()` from revealed leaves a new pitch unrevealed.
  - `stop()` prevents a pending reveal.

## Notes

- `buildPool` takes the instrument and validates the range against it, so S05/S06 settings and the S07 fixture instrument both go through it. AC5's "full written range" is `fullRange(instrument)`.
- `isNatural` goes in `src/core/pitch` rather than the drill because S06's sharps-off snapping will need it too.
- "Presses a key" is any key except auto-repeats and Ctrl/Meta/Alt combinations; clicks on the license link do not step. Clicks anywhere else on the page step.
- Flow logic lives in `src/app/card-flow.ts`, not core: it owns the timer, which the layer rule keeps out of the drill engine. Components stay untested (no DOM in the test setup), so the flow is tested through the controller.
- The static "drill imports nothing from render/app" check is F01-S07; sub-task 1 only asserts AC10's positive import list and the absence of `Math.random`.
