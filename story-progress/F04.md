## F04-S02: Judge rules

Story: [`F04-S02-judge-rules`](../docs/features/04-record-and-judge/stories/F04-S02-judge-rules.md)

Covers: AC1, AC2, AC3, AC4, AC5, AC6, AC7, AC8, AC9
- [x] Create `src/core/judge/index.ts`, importing only `../pitch` and `../instrument`. Frequency maths: `nearestPitch(hz): { pitch: Pitch; cents: number }` via `69 + 12 * log2(hz / 440)`, rounded, cents in [-50, 50] (AC1); `centsFrom(hz, expected: Pitch): number` as `1200 * log2(hz / toFrequency(expected))` (AC2); `judge(expected, hz, toleranceCents): "correct" | "incorrect"` with `Math.abs(centsFrom(...)) <= tolerance`, so an octave (1200¢) is always incorrect (AC3).
- [x] `frequencyBand(instrument): { minHz; maxHz }`: `toFrequency(soundingPitch(lowest) - 12)` to `toFrequency(soundingPitch(highest) + 12)`; 220 and ~2793.8 Hz for the alto C (AC8).
- [x] `interface Reading { time: number /* ms */; frequency: number | null; clarity: number; level: number /* dBFS */ }` (same field names as the S03 listener's reading, so it passes straight through). `interface StabilityOptions { band; clarity; gateDb; spreadCents; settleMs; holdOffMs }` and `DEFAULT_THRESHOLDS` (`clarity` 0.9, `gateDb` -55, `spreadCents` 25, `settleMs` 200, `holdOffMs` 500, no band) exported as a constant; every function takes them as parameters (AC7).
- [x] `createToneTracker(options): { reset(startMs: number): void; push(reading): number | null }`. `reset` sets the window start and clears state. `push` ignores readings before `start + holdOffMs` (AC6); a reading counts only when clarity, level and band all pass; a failing reading clears the run; while the run's max minus min in cents exceeds `spreadCents`, drop the oldest readings until it fits; when the run spans at least `settleMs` (newest time minus oldest), return the median frequency once and then return null until `reset` (AC4, AC5). Before the first `reset`, `push` returns null. Never reads a clock.
- [x] `tests/core/judge.test.ts`: A4 → A4 and 0, a few equal-tempered values, rounding at ±50; midway C5/C♯5 is +50 from C5 and -50 from C♯5; tolerance boundaries (exactly 40 correct, 40.01 incorrect), octave up and down incorrect; band for the alto C; reading sequences at 16.7 ms steps for steady tone, wobble within 25¢, jumps, slow breath glide (no verdict until it settles), rough start then steady, silence, low clarity, low level, 50 Hz hum at clarity 1, a second tone after the first (no second report), readings inside the hold-off, and custom thresholds passed in. Assert the source imports exactly `../pitch` and `../instrument` (like `drill.test.ts`) and that `drill` does not import `judge` (AC9).
- [x] Write `docs/architecture/modules/judge.md` (purpose, interface, thresholds as provisional with a link to the spike, dependencies, tests) and add it to `modules/README.md`. `make verify` (AC9).

## F04-S03: Microphone pitch stream

Story: [`F04-S03-microphone-pitch-stream`](../docs/features/04-record-and-judge/stories/F04-S03-microphone-pitch-stream.md)

Covers: AC1, AC2, AC3, AC4, AC5, AC6, AC7, AC8, AC9, AC10

- [x] `src/audio/listener.ts`: `createListener(audio: Audio, env: ListenerEnv)` where `ListenerEnv = { getUserMedia: ((c) => Promise<StreamLike>) | null; requestFrame(cb: (timeMs) => void): number; cancelFrame(id): void }` and `browserListenerEnv()` builds it from `navigator.mediaDevices` and `requestAnimationFrame` (null `getUserMedia` when absent). `PitchReading { time; frequency; clarity; level }` matching the judge's `Reading`. `start(onReading): Promise<{ status: "running" } | { status: "locked" } | { status: "unavailable"; reason: "denied" | "no-device" | "unsupported" }>`:

- [x] `tests/audio/listener.test.ts` with fake media devices, fake frames and the fake context: constraints passed, readings with time/frequency/clarity/level, stop releases tracks and stops readings, stop twice, denied/no-device/unsupported/other errors, throwing `getUserMedia`, locked (no request), unlocked-but-resuming proceeds, double start, stop during in-flight start, restart after stop, shared `Audio` instance with the tone player (AC1-AC6, AC9).

## Notes

- **Graph location (S06 leaves it to the breakdown):** geometry in `src/render/graph` (pure, knows only pitch and cents), the SVG component in `src/app`, like staff and tab.
- **Reading shape:** `src/audio` may import only `../core/pitch`, so the listener's `PitchReading` and the judge's `Reading` are separate types with the same fields (`time` ms, `frequency` Hz or null, `clarity`, `level` dBFS) and pass through structurally.
- **Clock:** the hold-off starts from `now()` at the window's opening; the app uses `performance.now()`, the same timebase as the `requestAnimationFrame` timestamps the listener stamps readings with.
- **Listener lock rule** mirrors the tone player: locked when the context is not running and no unlock has been requested.
- **Unavailable** is sticky for one flow (until the settings view closes or the page is shown again); an unexpected start failure is treated as unavailable.
- **Reveal height with judging on** gets its own fixed height (a modifier set from the setting), so judge off keeps the F03 look (S06 AC8) and the staff never moves.
- **Cancelled start (S03):** a start cut short by `stop()` resolves `locked` (nothing opened; the next start retries). The S05 flow drops it by generation anyway.
- **Settings notice (S04):** `Settings` already renders `JUDGE_UNAVAILABLE` in the Microphone section when `judgeUnavailable` is true; S05 only passes the prop.
- Tolerance input step is 1¢; the core accepts any finite number in 10 to 45.
