## F10-S04: Follow the song

Story: [`F10-S04-follow-the-song`](../docs/features/10-scrolling-song-view/stories/F10-S04-follow-the-song.md)

Covers: AC1, AC2, AC3, AC4, AC5, AC6, AC7, AC8, AC9, AC10, AC11, AC12, AC13
- [ ] `src/app/follow.ts` (new, no Preact): `FOLLOW_FRACTION = 1 / 3` and `SCROLL_MS = 450` (a first guess, tuned in the final check). Pure `followTop({ rowTop, viewport, header, bar, maxScroll })` is `rowTop - header - FOLLOW_FRACTION * (viewport - header - bar)` clamped to `[0, max(0, maxScroll)]` (AC1, AC3, AC10). `easeInOut(t)`. `createScroller({ scrollY, scrollTo, now, frame, cancelFrame })` with `to(top, smooth)` and `dispose()`: smooth tweens from the current position over `SCROLL_MS` by animation frame, a new `to` restarts from where it is, not smooth cancels any tween and jumps, and a target equal to the current position does nothing. Tests in `tests/app/follow.test.ts` with a fake clock and frames: `followTop` for the first line (clamped to 0), a middle line, the last line (clamped to the end) and a song that fits (0); the tween reaching its target at `SCROLL_MS`; a restart mid-tween; a jump cancelling a tween; `dispose`.
- [ ] `src/app/SongOverlay.tsx`: new prop `onRow(row)`, called from the frame loop when `playheadPlace`'s row differs from the last one reported; the last one resets at each loop start, so a run's first frame reports row 0 during the count-in (AC2, AC4). Following the playhead, not the current note, starts the scroll as the playhead reaches the line even when the line opens with a rest or a tie carries over the break.
- [ ] `src/app/Staff.tsx` `SongStaff`: new props `phase` (`Card`'s `timed`), `header` and `bar` refs. One scroller over `window` per mount, disposed on unmount. On `onRow(r)`: row top in page px is `box.getBoundingClientRect().top + scrollY + layout.rows[r].top * box.clientWidth / layout.width`; header and bar from `offsetHeight`; `innerHeight`; `maxScroll` from `documentElement.scrollHeight - innerHeight`; smooth unless `matchMedia("(prefers-reduced-motion: reduce)")` matches (AC1, AC2, AC5). The target is measured afresh each time. Keep the last row in a ref; a window `resize` while `playhead.running` jumps to that row's target (AC6). When `phase` becomes `"ready"`, jump to 0, which also cancels any tween (AC8). Ending or stopping cancels nothing, so a tween in progress finishes (AC9); the summary reports no new row, so the page stays (AC7); a restart reports row 0 and scrolls back (AC7). Judging off follows the same path (AC11).
- [ ] `src/app/Card.tsx` and `App.tsx`: `App` holds a `useRef` on `<header>` and passes it to `Card`, which passes `header`, `bar` and `timed` to `SongStaff`. Random and untimed cards have no `SongStaff`, so nothing scrolls them (AC12).
- [ ] `make verify` passes. `docs/architecture/modules/app.md`: following the song (`follow.ts`, `onRow`, resize, reduced motion, the jump on ready), tests list (AC13).

## Notes

- **Follows the playhead's row, not the note's line.** The design's modules list says the line is found from the current note with `lineOfNote`. The checklist uses the row the overlay's playhead is on (S04), so the scroll starts exactly when play reaches the line (F10-S04 AC4) even when a line opens with a rest or a tie runs over the break. `timed-flow.ts` stays unchanged as the design says.
- **Music is capped by window height** (S03) so two lines, the header and the bar fit at 1024x768 (F10-S03 AC7) at the default 2 bars per line. Wide but short windows draw the music smaller than F09 did.
- **A short song's bar sits at the bottom of the screen**, not directly under the music (S03). At the end of a long song the font licence footer is below the bar.
- **F10-S04 AC9 and Settings.** Opening Settings unmounts the card, which disposes the scroller, so a tween in progress stops there; there is nothing left to scroll to. Song end and a hidden page let it finish.
- **Constants are first guesses**, tuned in the final check: `FOLLOW_FRACTION` 1/3, `SCROLL_MS` 450, `ROW_SPACING` 0, `--song-chrome` about 13rem.
- The header shows no title or tempo while Settings is open (F10-S01 AC7: "as it does today").
- The tempo is rounded to a whole number for display.
