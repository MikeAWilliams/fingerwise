## Notes

- **Node types in tests:** `@types/node` is not installed and adding it needs the user's agreement, so `tests/node-modules.d.ts` declares only the `node:fs` and `node:crypto` functions `tests/data/fonts.test.ts` uses.

- **License source:** upstream has no license file in the repo; its README links the OFL, and the font's embedded copyright record (name ID 0) holds the copyright line plus the full OFL 1.1 text. That record is the "upstream" text used for AC6. The font is only on the `gh-pages` branch; commit `671deb7` (2017-01-19) is the last one touching it.
- **Folder:** `data/fonts/` (from the design), holding the `.ttf`, `OFL.txt` and `README.md`.
- **License notice in the build:** shipped as an emitted `OFL.txt` asset linked from a small footer, so it is both in `dist/` and visible to the user.
- **No DOM in tests:** vitest runs in Node and adding jsdom would be a new dependency. Logic lives in pure functions (`tabView`, `startRevealTimer`, `loadFont` with injected `FontFace`); the Preact components stay thin and are checked by hand.
- **Font family:** registered under the file name without extension, so the instrument JSON's `tablature.font` alone picks the font.
- **Font load starts on page load**, not at reveal, so it is usually ready by the time the delay ends.
