## Sub-task 5: Tone player

Covers: AC1, AC2, AC3, AC5, AC6, AC7
- [x] `src/audio/tone.ts`: `createTonePlayer(audio: Audio): TonePlayer` with `play(pitch: Pitch, seconds: number): void`, `stop(): void`, `unlock(): void` (delegates to `audio.unlock()`). Constants `FADE_SECONDS = 0.02`, `PEAK_GAIN = 0.3`
- [x] `play`: does nothing when `audio.context()` is null, or when the context is not `"running"` and `audio.unlockRequested` is false (AC6 lock half: nothing queued). Otherwise calls `stop()` first (AC3), then creates a sine oscillator at `toFrequency(pitch)` into a gain into `destination`; from `t0 = currentTime`: gain 0 at `t0`, ramp to `PEAK_GAIN` at `t0 + fade`, hold at `t0 + seconds - fade`, ramp to 0 at `t0 + seconds`; `osc.start(t0)`, `osc.stop(t0 + seconds)` (AC1). `fade = min(FADE_SECONDS, seconds / 2)` so a short duration still gives a valid envelope. When the context is still suspended after an `unlock()`, this schedules on the frozen clock and sounds once it runs (AC6)
- [x] `stop`: when a tone is current, `cancelScheduledValues(now)`, `setValueAtTime(gain.value, now)`, ramp to 0 at `now + FADE_SECONDS`, `osc.stop(now + FADE_SECONDS)`, forget it; a no-op otherwise (AC2). The oscillator's `onended` clears the current tone if it is still the same one
- [x] Every Web Audio call in `play` and `stop` is inside `try/catch`; nothing throws or rejects (AC5)
- [x] `tests/audio/tone.test.ts` with the fake: frequency and `"sine"` type; envelope times for 1.5 s; a 0.01 s duration gives non-decreasing ramp times; oscillator stop at the duration; `stop()` fades and stops, second `stop()` and `stop()` before any play do nothing; a second `play` stops the first before creating new nodes; locked context without unlock creates no nodes; suspended context after `unlock()` schedules nodes; null factory and a context whose `createOscillator` throws never throw
- [x] New `docs/architecture/modules/audio.md` (purpose, `context.ts` and `tone.ts` interfaces, the lock rule, dependencies `../core/pitch` only, tests); add `audio` to the list in `docs/architecture/modules/README.md` (AC7)
- [x] `make verify`
