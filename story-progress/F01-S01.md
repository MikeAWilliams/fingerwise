## Notes

- **Pitch is a branded MIDI number.** The vision offers MIDI or name plus octave; MIDI makes transposition and ranges plain arithmetic. Recorded in `modules/pitch.md`, not an ADR, since it answers no open question.
- **Octave mapping of the research labels.** The research note labels the alto C range A to F² with relative octave marks. Read as written pitch A3 to F5 (per ADR 0003): unmarked A, A♯ and B are A3-B3; unmarked C through G♯ are C4-G♯4; ² A through F are A4-F5. So the glyphs run `A` (A3) to `U` (F5) one letter per semitone.
- **Only `♯` is accepted**, not `#`, so parse then format always returns the input (AC1). Flats and `B♯`/`E♯` are rejected.
- **The loader takes parsed JSON (`unknown`)**, not a path: `src/core` cannot read files. The app will import the JSON at build time; tests import it directly.
- **Invalid instruments are built in the tests** by deep-copying the alto C JSON and changing one field, rather than as fixture files. S07 adds the real fixture instrument under `tests/`.
- **Font reference is the file name** (`Open-12-Hole-Ocarina-1.ttf`); S03 adds the file in `data/fonts/` and decides how `render/tab` maps it to a font family.
- **`ClefName` includes `treble-8vb` and `bass`** because S07 renders those; the alto C uses `treble`. No `key` field: AC3 does not list it and ADR 0003 makes key a transposition matter.
- **Glyph strings are opaque** (ADR 0002): validated as non-empty strings only.
