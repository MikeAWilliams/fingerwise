## F09-S02: Coverage core

Story: [`F09-S02-coverage-core`](../docs/features/09-timed-scoring/stories/F09-S02-coverage-core.md)

- [x] New `src/core/coverage/index.ts`. Its imports are `../pitch`, `../judge`, `../song` and `../instrument` only (AC13). Constants in one exported block: `EDGE_GRACE_MS = 40`, `WRONG_RUN = 3`, `TIMING_TOLERANCE_MS = 60`, `GAP_DIP_DB = 10`, `GAP_MEDIAN_WINDOW_MS = 100`, `MIN_SCORED_SPAN_MS = 50`, `RIGHT_NOTE_BAND_CENTS = 50`, `TRACE_SPAN_CENTS = 150`, and `MIN_GRADED_MS` derived as `2 * EDGE_GRACE_MS + MIN_SCORED_SPAN_MS` (AC11).
- [x] Types: `CoverageReading { time (ms, song time), frequency, clarity, level }` (the judge's `Reading` shape); `EnvelopeBlock { time (ms, song time, block end), level (dBFS) }`; `CoverageOptions { toleranceCents, checks: StabilityOptions, sounding(written: Pitch): Pitch }`.
- [x] `buildTimeline(song, tempo)`: `notes` (`{ index, written, startMs, endMs, graded }`, using the note's written length, not its slot), `rests` (from one note's end to the next note's start, as `songBars` finds them, `{ startMs, endMs, graded }`) and `joins` (`{ before, after, atMs, kind: "plain" | "slurred" }`, from `slurred`, made only between notes with no rest between them). `graded` is `length >= MIN_GRADED_MS` (AC1, AC5).
- [x] Classifying: `classify(reading, expectedSounding, options)` gives `right` (in tune or not, with cents) when `passesChecks` holds and `nearestPitch` is the expected pitch. Otherwise a passing reading is wrong-pending. The run tracker confirms `wrong` once `WRONG_RUN` readings in a row share the same other nearest pitch; the whole confirmed run counts as wrong from its first reading, and until then it counts as silent. Anything else is silent. Each reading covers the time until the next reading (AC2).
- [x] `createCoverageRun(timeline, options)` with `pushReading(r)`, `pushEnvelope(blocks)`, `progress()` and `finish()`. Each reading is classified against the note or rest due at its time. Segments (`{ startMs, endMs, kind: right-in-tune | right-out | wrong | silent, points }`, runs of the same class merged as the design says; `points` is `{ timeMs, cents }` per sounding reading, cents from the expected pitch, wrong readings included, for the S06 trace) are kept per note and rest, and a note or rest is finalised once song time passes its end plus `TIMING_TOLERANCE_MS` and the median window. `progress()` returns the segments and the faults found so far, appending to arrays without recomputing finalised items (AC10). Only the last `WRONG_RUN - 1` readings can change on a later push.
- [x] Coverage: a note's share of `[start + grace, end - grace]` covered by right readings. At a slurred join the grace on that side forgives only readings of the neighbour's pitch, so silence inside it still counts against the note (AC3). A rest's share of its own graced span covered by silent readings (AC4). Song coverage is the unweighted mean over graded notes and rests; in-tune share is in-tune time over right time per note, and the song figure is the mean over notes with any right time. `tooShort` counts the ungraded notes (AC5, AC6).
- [x] Timing per note: the start and end edges are its first and last right readings, even when silence breaks the note in between. Started late / ended early go beyond `TIMING_TOLERANCE_MS`. Started early / ended late mean the expected pitch's nearest-note match runs unbroken from beyond the tolerance before the start, or past the end, which uses readings classified against the neighbour too. A note with no right time has no edges, and a same-pitch plain join with no gap has no edge on either side. Each figure is `{ faults, withEdge }` (AC7).
- [x] Separation for each plain join: within `atMs ± TIMING_TOLERANCE_MS`, a block whose level is at least `GAP_DIP_DB` below the median of the blocks within `GAP_MEDIAN_WINDOW_MS` around it, followed by a recovery, or a silent reading there. Figure: `{ notSeparated, plainJoins }`. Slurred joins are skipped (AC8).
- [x] Tuning list: for each written pitch, average the cents of every reading within `TRACE_SPAN_CENTS` of the expected sounding pitch while a note of that pitch is due. Keep the pitches whose `|avg| > toleranceCents`, sort worst first and take three (AC9).
- [x] `tests/core/coverage.test.ts` with generated readings at 16.7 ms and envelopes at 2.67 ms in song time. Cover every case in the story's test approach, plus eighths at ♩ = 80 and faster, a slurred join with and without a break, and both grace rules at slurred joins (AC1–AC10).

## Notes

- **Note heads (decided with the user):** S03 keeps the current redraw-per-note, without marks. From S04 the staff is drawn only when the line pair changes, and the current note is made black by recolouring its existing SVG elements. That satisfies S03 AC7, S04 AC5 and S05 AC8 together.
- **Sounding pitch:** the coverage core classifies against `options.sounding(written)` and keeps written pitch for the tuning list, so the instrument's transposition stays a parameter.
- **Wrong runs:** a confirmed run of `WRONG_RUN` readings is wrong from its first reading. Until it is confirmed, its readings count as silent, so the last two readings in `progress()` can still change.
- **Song time 0** is the first note's start (the first slot). Readings from the count-in are fed with negative times, so "started early" on the first note can be seen; the count-in is not a graded rest.
- **Reading time** is `currentTime` when the analyser is read, which is the newest sample. The window's 43 ms blur is absorbed by the edge grace and the measured input allowance, as the design assumes.
- **Times:** the staff layout is in beats (the staff knows no tempo), and the app converts beats to ms with the song's tempo. The coverage core works in ms.
