## Notes

- **State shape:** the passing wrong verdict rides in `CardState.verdict` while `revealed` is false, rather than a new field. `hint: boolean` is added in S02, where it is first needed. Both stay inside `src/app`.
- **When a card waits:** waiting is decided per card at the moment it matters: `wait` on, `listening` `running`, and the window open. A card dealt while `opening` that then settles to `running` therefore waits from then on. A tracker or grade that throws closes the window, which ends the wait, so the card falls back to its reveal timer instead of sticking.
- **Clear timer:** the wrong-verdict clear timer is separate from the single reveal/advance slot, so the hint (reveal delay) still fires on time while a wrong verdict shows.
- **S01 alone:** until S02 lands, a waiting card ignores the reveal delay and taps. A song can then only move on with a correct note; this is as the S01 Notes describe.
- **Stored use song on with an empty text** (only possible by hand-editing storage) now loads the example with use song still on, and the load-time parse keeps it on. This is accepted as harmless.
- **abcjs on a fresh profile:** because the default text is non-empty, the load-time parse (and so the abcjs chunk) now runs on every first load. It stays a dynamic import, so `tests/pwa/precache.test.ts` still holds.
- S03 is independent of S01 and S02 and keeps its number order.
