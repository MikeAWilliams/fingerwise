  - `interface StaffOptions { clef: ClefName; accidentals: "sharps"; keySignature: "C"; lowest: Pitch; highest: Pitch }` (`ClefName` from `../../core/instrument`, `Pitch` from `../../core/pitch`). `accidentals` and `keySignature` are single-member unions for now, so the parameter exists (AC5) without inventing behavior
  - `class StaffRangeError extends Error`
  - `noteLayout(pitch, options): NoteLayout` returning `{ key, accidental, clef, annotation }`:
    - throws `StaffRangeError` (naming the pitch with `formatPitch`) if `pitch` is outside `lowest`..`highest`
    - `key` is the VexFlow key, e.g. `c/5`, `f#/4`, built from `formatPitch` (letter lowercased, `♯` → `#`, then `/octave`)
    - `accidental` is `"#"` for a sharp pitch, else `null` (C major, no key signature: AC3)
    - `clef`/`annotation`: `treble` → `("treble", undefined)`, `bass` → `("bass", undefined)`, `treble-8vb` → `("treble", "8vb")` with the key shifted up one octave so the written pitch reads on an 8vb staff. Only treble is tested here (S07 covers the rest)
  - `buildNote(layout): StaveNote`: a whole note `new StaveNote({ keys: [layout.key], duration: "w", clef: layout.clef })`, plus `new Accidental("#")` via `addModifier` when `layout.accidental` is set
  - `ledgerLines(note: StaveNote): number`: from `note.getKeyProps()[0].line` (bottom line = 1, top = 5): `line < 1` → `Math.floor(1 - line)`, `line > 5` → `Math.floor(line - 5)`, else 0

## Notes

- **Testing (user decision, 2026-10-25):** no DOM library. Tests inspect VexFlow's `StaveNote` model (staff line, modifiers) in Node; the SVG is checked by hand.
- **Font bundle:** `vexflow/bravura` embeds the Bravura music font. The default `vexflow` entry embeds every font (larger) and `vexflow/core` loads fonts at runtime, which would break offline use later.
- **Module placement:** the drawing code is framework-free in `src/render/staff`; the Preact wrapper lives in `src/app` so render stays independent of the UI.
- **Clef parameter:** `ClefName` is reused from `src/core/instrument`. The `treble-8vb` mapping (8vb clef, note an octave up on the staff) is a best guess; S07 tests it and may adjust.
- **Blocked (2026-10-25):** `bun add vexflow@5.0.0` (sub-task 1, first item) was denied by the auto mode permission classifier, with no reason given. Nothing else was started, since every other item needs VexFlow. Needs the user to run the install or allow it.
- **Fixed pitch:** `C5`, chosen so the first card sits mid-staff. S04 replaces it with the random pick.
