## Sub-task 1: Verify and deploy workflow

Covers: AC1, AC2, AC3, AC4, AC6
- [ ] Create `.github/workflows/deploy.yml`, named `Verify and deploy`. Triggers: `push` (no branch filter) and `workflow_dispatch`.
- [ ] Top-level `permissions: contents: read`.
- [ ] Top-level `concurrency: { group: pages, cancel-in-progress: false }` so deploys never overlap. Put it at job level on `deploy` instead if it would otherwise queue or cancel `verify` runs on other branches; `verify` must stay parallel across branches.
- [ ] Job `verify` (`runs-on: ubuntu-latest`): `actions/checkout@v4`; `oven-sh/setup-bun@v2` with `bun-version: 1.4.4` (pinned, matches local); `make install`; `make check`, `make typecheck`, `make test`, `make build`. Same checks as `make verify`, split into steps so a failure names the step. Upload `dist/` with `actions/upload-pages-artifact@v3` (`path: dist`), but only on the refs that may deploy (same condition as `deploy`, below), so other branches do no upload.
- [ ] Job `deploy`: `needs: verify` (AC2). `if:` is one expression built from `github.ref == 'refs/heads/main'` plus, on its own line under a comment, the temporary clause `github.ref == 'refs/heads/story/F02-S01-deploy-github-pages'` (AC4). Comment says it is removed before the story is accepted (sub-task 3). Manual runs: `workflow_dispatch` is allowed only from `main` through the same `main` clause, so no extra condition.
- [ ] `deploy` job permissions: `pages: write`, `id-token: write` (contents read is inherited from the top level; restate `contents: read` if job-level permissions replace it). `environment: { name: github-pages, url: ${{ steps.deployment.outputs.page_url }} }`. Single step `actions/deploy-pages@v4` with `id: deployment`.
- [ ] Share the deploy condition between the upload step and the `deploy` job without duplicating it, or comment clearly that the two must match. Prefer a single `if:` on the upload step and `deploy`, both pointing at the one commented clause.
- [ ] Confirm the YAML parses: `bun x --bun yaml-lint` is not allowed (new tool); instead run `python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/deploy.yml'))"` if PyYAML is present, otherwise re-read the file carefully. Biome does not touch it.
- [ ] `make verify` passes.
