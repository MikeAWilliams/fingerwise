# Security policy

## Reporting a problem

Please report security problems privately, not in a public issue. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and which browser or device you used. fingerwise is a small project maintained by one person, so please allow some time for a reply.

## Supported versions

Only the latest version is supported: the live site at <https://mikeawilliams.github.io/fingerwise/> and the current `main` branch. The app is static, runs entirely in the browser, and has no accounts or server, so the most likely issues are in its dependencies or its build and deploy workflow.
